# Chitranah Study Hub — V7

Fresh GitHub Pages starter for the new V7 build.

## Current contents
- Attractive responsive home page
- 15 uploaded mock-test HTML files preserved in `tests/`
- Searchable mock-test grid
- No Supabase keys are stored in this package

## Important
This is a fresh V7 foundation. Supabase authentication/database, student dashboard, results, progress, leaderboard, notes and admin panel will be connected in later steps.

## GitHub replacement steps
1. Download and extract this ZIP on your computer.
2. Open your GitHub repository: `chitranah-study-hub`.
3. Make a backup of the old repository if you want to keep it.
4. Remove the old website files from the repository (do not delete the repository itself).
5. Upload the extracted V7 files/folders so `index.html` is in the repository root.
6. Commit the changes.
7. In Settings → Pages, keep GitHub Pages enabled from the `main` branch and `/ (root)`.
8. Wait for the deployment, then open the GitHub Pages URL.

Do not upload Supabase service-role keys to GitHub. Only the public anon/publishable key belongs in frontend configuration later.
